# Runbook: заказ → видео за 30–45 минут

## 1. Бриф клиента

Спросить (форма или сообщение):
1. Ссылка на репозиторий или сайт.
2. Название продукта и одна фраза «что это».
3. Тон (пресет или своими словами).
4. Пакет: Launch или Launch Pro; нужен ли rush.
5. Своя музыка? Если нет — без музыки или лицензированный трек.

Не начинать работу до оплаты (кроме бесплатных видео для портфолио).

## 2. Подготовка (5 мин)

```bash
git clone --depth 1 <repo> client && cd client      # или сохранить сайт: npx hyperframes capture <url>
npx hyperframes doctor                               # один раз на машине
```

## 3. Генерация (20–30 мин)

В Claude Code или Codex из папки клиента:

```text
/brag --tone "<тон клиента>" --no-music
```

Для Launch Pro — после первого видео:

```text
/brag --format vertical   (затем --format square), тот же план
```

Если установлены агенты из `agents/`, `/brag` сам раздаст шаги inspector → planner → composer → deliverer.

## 4. Проверка перед сдачей (5 мин)

- [ ] Посмотреть видео целиком со звуком.
- [ ] Название продукта и цитаты написаны без ошибок.
- [ ] Каждая надпись успевает прочитаться.
- [ ] Первые 2 секунды цепляют.
- [ ] `npx hyperframes check` — 0 ошибок.

## 5. Сдача

- `brag.mp4` (+ vertical/square для Pro) и `share-copy.txt` — ссылкой на Google Drive / Dropbox.
- Попросить разрешение показать видео в портфолио и короткий отзыв.
- Удалить копию приватного кода.

## Правки

Правка = новая подсказка к `/brag` с тем же `brag-plan.md`: «оставь план, поменяй хук на …». Обычно 5–10 минут.
