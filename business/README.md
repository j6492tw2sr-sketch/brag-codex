# Бизнес: launch-видео на заказ

Продаём не код, а результат: короткое видео для запуска продукта, собранное `/brag` из репозитория или сайта клиента. Себестоимость — ~30–45 минут и токены; цена — $29–79.

Почему продаём услугу, а не навык: у оригинального `latent-spaces/brag` нет лицензии (см. `NOTICE.md`), поэтому перепродавать сам код нельзя. Видео, которые вы делаете инструментом, — ваша работа.

## Что сделать вам (то, чего не могу я)

1. **Приём оплаты.** Создайте платёжные ссылки на два пакета (Gumroad, Lemon Squeezy, Ko-fi Shop или Stripe Payment Links). Цены — в [offer.md](offer.md).
2. **Канал заказов.** Почта или Telegram для заказов + форма с вопросами из [order-runbook.md](order-runbook.md#1-бриф-клиента).
3. **Портфолио.** Закрепите пост на X с 2–3 видео из `examples/*/brag.mp4` и `docs/assets/brag-about-brag.mp4` + текст из [outreach.md](outreach.md#закреплённый-пост).
4. **Первые 10 клиентов.** Каждый день 15 минут по сценарию из [outreach.md](outreach.md).

## Первая неделя

| День | Действие | Цель |
|---|---|---|
| 1 | Платёжные ссылки, закреплённый пост | Можно принять оплату |
| 1–2 | 3 бесплатных видео для чужих свежих запусков (#buildinpublic, Show HN, Product Hunt) | Портфолио на реальных продуктах + отзывы |
| 3–7 | 10 ответов/ЛС в день по шаблонам | 1–3 платных заказа |
| 7 | Посчитать: сколько ЛС → ответов → заказов | Понять, что масштабировать |

Бесплатное видео — главный продающий ход: автор запуска почти всегда репостит ролик про свой продукт, и это реклама вам.

## Риски (прочитайте до первого платного заказа)

- **Музыка.** Лицензия комплектных треков ende.app не проверена (`skills/brag/assets/music/README.md`). Для платных заказов: `--no-music`, трек клиента или трек с явной коммерческой лицензией. SFX (Kenney.nl) — CC0, можно.
- **Чужой бренд.** Видео делается только по просьбе владельца продукта и только из его материалов.
- **Приватный код.** Если клиент даёт доступ к закрытому репозиторию — удалить копию после сдачи.
